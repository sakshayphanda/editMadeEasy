# Edit Made Easy

- Angular standalone application for everyday utilities.
- `src/app/features/`: feature pages, loaded lazily through `app.routes.ts`.
- `src/app/core/`: application-wide services and infrastructure when needed.
- `src/app/shared/`: reusable UI components, directives, and pipes when needed.
- SCSS styles; strict TypeScript and Angular templates; npm package manager.
- Commands: `npm start`, `npm run build`, `npm test -- --watch=false`.
- `src/app/features/audio/`: compressor, volume increaser, trimmer, and MP3 converter share an editor. `audio-tools.ts` drives home cards, navigation, and `/audio/:id` routes. The converter uses `/audio/converter` and exports the full audio at 192 kbps with unity gain; input formats depend on browser decoding support.
- Audio stays on-device: Web Audio decodes at 44.1 kHz; a worker encodes MP3 using `@breezystack/lamejs`. Outputs are lossy; compression is not guaranteed to reduce an already compressed input.
- Compressor optionally caps output at 1/2/4/5/10/20 decimal MB (1 MB = 1,000,000 bytes), automatically selecting among existing bitrates and checking actual encoded size. Oversized results are rejected; minimum target bitrate is 96 kbps stereo or 64 kbps mono. No-limit mode preserves manual bitrate selection.
- `/audio/youtube` is a separate online downloader; `server/youtube.mjs` calls the anonymous Samplecut API (60-minute sources, 10 requests/10 minutes per server IP). `npm start` starts Angular and the loopback API on port 3001 via `scripts/dev.mjs`; production needs a same-origin `/api/` proxy. `ffmpeg-static` transcodes MP3 at standard 8–320 kbps rates (8–24 mono; 144 kbps requires 22.05 kHz); 320 passes through. Existing local editors do not use this backend.
- Audio limits: 100 MB, 1 hour 30 minutes, mono/stereo. Volume boosts apply the requested gain to quiet samples, with a stereo-linked per-frame soft knee above 0.8 and a PCM ceiling of 0.95. A loud peak does not reduce gain across the entire recording. This edits only worker copies; unity gain is unchanged.
- Audio durations and trim inputs use `hh:mm:ss`; processing uses seconds. The initial trim endpoint retains the exact file duration, including fractional seconds.
- `/audio/denoise` uses stereo-linked spectral subtraction in `audio-denoise.ts` in the encoding worker. Overlapping Hann windows and a median broadband noise estimate reduce hiss beneath louder audio; this is not voice isolation. The -60 to -20 dB noise floor (default -40) sets minimum suppression sensitivity. Exports the full recording at 192 kbps and edits only the worker's copied samples, with fixed-size processing buffers.
- Volume exports choose among 192/128/96/64 kbps based on source size and duration, then verify actual MP3 size and retry lower rates if needed. Stereo volume exports stop at 96 kbps: the current lamejs encoder can output silence at 64 kbps stereo (reproduced by decoding the exported MP3). If the minimum bitrate cannot fit, retain the larger result for preview. Any audio output larger than its source requires an unchecked-by-default confirmation checkbox before the download link appears; reset confirmation whenever the result is cleared. Other tools retain their existing bitrate behavior. All audio results show original/output sizes and the actual increase, decrease, or unchanged size with a percentage.
- The expanded video/audio/PDF/converter catalog is `features/suite/tools.json`, shared by Angular routing/home search and Node processing. Existing local audio routes take precedence. The reusable `Suite` workspace handles ordered uploads, recording, audio selection, settings, cancellation, previews, and downloads with fresh confirmation for larger audio results; new server routes use `/api/tools/:group/:id`.
- `server/tools.mjs` handles bounded multipart uploads and per-request temp cleanup; `tool-processors.mjs` dispatches FFmpeg, Python (`file-tools.py`), LibreOffice, Calibre, 7-Zip, and speech. `/api/tools/capabilities` caches engine availability until restart. `npm run setup:tools` installs `.venv`; `--mac-engines` adds ignored `.tools` apps on Apple Silicon. Engine paths can be overridden with `TOOLS_*` variables (README).
- Server suite limits: 100 MiB / 20 files per request, one active suite job, four-minute timeout, 90-minute media exports. PDF operations: 500 pages; image export: 100 pages. PDF→Word extracts text, PDF→Excel extracts tables; no OCR. Video editor is single-clip; no multitrack timeline, cloud-drive imports, accounts, or subscriptions. Browser recording stays local; server edits upload files.
